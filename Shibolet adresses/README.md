# שיבולת | הסדרת כתובות

אפליקציית Streamlit בעברית לפיצול כתובות מקובצי גבייה ולייצוא התוצאות ל־Excel.

## הפעלה מקומית

```bash
python -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python -m streamlit run app.py
```

ב־Windows הפעילו את הסביבה באמצעות `.venv\Scripts\activate`.

## שימוש

1. העלו קובץ XLSX או CSV. בקובץ Excel בחרו גיליון.
2. בחרו את העמודה שמכילה את הכתובת.
3. בדקו את הפיצול וערכו את השדות בטבלה לפי הצורך.
4. הורידו את קובץ ה־Excel. הקובץ כולל את העמודות המקוריות ועמודות תוצאה נוספות.

דוגמה לפורמט נתמך היא `הרצל 12/4, ראשון לציון`. אפשר לציין דירה גם בצורה `הרצל 12 דירה 4`. היישוב מזוהה כשהוא מופיע אחרי פסיק. רשומות שהכללים לא הצליחו לפצל מסומנות לבדיקה ידנית. הפיצול מבוסס על תבניות כתיבה.
